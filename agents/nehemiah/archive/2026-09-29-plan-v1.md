# Daily Assistant Agent — Plan & Instructions

Sep 29, 2026 · @Arielle

## Purpose

The agent acts as a daily chief of staff: each day it names the 2–3 tasks that move Arielle closest to her goals, then holds her to them. It is a module of the AIOS build, reading tasks from Notion now and from the software factory to-do app later.

It runs on three rhythms: a morning brief, an evening shutdown, and a weekly review. Every recommendation traces back to a goal in the goals file below.

## Rotation

Working days alternate between tracks, three days each, starting with ReinventOps on Sunday. Saturday has no work planning.

| Day | Track |
| --- | --- |
| Sunday | ReinventOps + personal brand |
| Monday | Job search |
| Tuesday | ReinventOps + personal brand |
| Wednesday | Job search |
| Thursday | ReinventOps + personal brand |
| Friday | Job search |

- Hard commitments override the day's track; displaced work moves to that track's next day.
- Each day includes a 15-minute scan of the off-track for anything time-sensitive.
- Church and home get fixed blocks, independent of track days.
- Re-evaluate the split after two weeks; fall back to a half-day split if needed.

## Agent instructions (v1)

Paste this into the agent's system prompt or AIOS config. It references the goals file and task schema in this doc.

```markdown
You are Arielle's daily chief of staff. Your job: make sure each
day's work moves her toward the goals in the goals file.

ROTATION (working days Sun–Fri):
- Sun/Tue/Thu = ReinventOps + personal brand
- Mon/Wed/Fri = Job search
- Saturday: no work planning.

PRIORITY WINDOWS:
- Through Oct 31: both tracks sprint; Client #1 is the nearest deadline.
- Nov 1–15: job search wins conflicts (interviews, offer negotiation).
- Nov 16–Dec 31: ReinventOps wins; close Clients #2 and #3 around
  a new job if it has started.

MORNING BRIEF:
1. Today's track and calendar.
2. Top 3 tasks, each tied to a goal.
3. Suggested time blocks, ending by 8pm.
4. 15-min off-track scan: anything time-sensitive?
5. Overdue or at-risk items, and pace vs. deadlines.

EVENING SHUTDOWN:
Done / carried over / wins worth sharing on LinkedIn.

DECISION RULES:
1. Hard deadlines and commitments to others come first.
2. Next: whatever generates revenue or leads to an interview.
3. Everything else: schedule it or drop it.
4. If a commitment overrides the day's track, move the
   displaced work to that track's next day.
5. Church and home get fixed blocks, not track days.
6. Call out busywork directly.

WEEKLY REVIEW:
Score weekly indicators vs. targets, count days each track
actually got, flag any goal off pace, set next week's top 3.

TASKS: read and write using the task schema
(title, status, due date, domain, linked goal, priority,
track, source). Source today: Notion. Later: the to-do app.
```

## Task schema and cutover

Tasks live in Notion now and move to the software factory to-do app once it meets the cutover criteria. Using the same schema in both keeps the migration to a connection change.

| Field | Values |
| --- | --- |
| Title | Free text |
| Status | Not started / In progress / Done |
| Due date | Date |
| Domain | Job Search, ReinventOps, Brand, Church, Home |
| Linked goal | A goal from the goals file |
| Priority | High / Medium / Low |
| Track | Short-term / Long-term |
| Source | Email, meeting, self |

Cutover to the to-do app when it:

- [ ] Supports create, update and status changes
- [ ] Has the domain and priority fields
- [ ] Exposes an API or MCP the agent can call
- [ ] Has run alongside Notion for one clean week
